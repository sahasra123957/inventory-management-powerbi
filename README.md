# Inventory Management & Reorder Optimization Dashboard

## Project Overview

This project is an end-to-end Power BI data analytics solution designed to monitor inventory levels, analyze product demand, identify stock shortage risks, and provide data-driven reorder recommendations.

The dashboard helps businesses make better inventory decisions by reducing stock shortages and avoiding excess inventory.

## Objectives

- Analyze product sales and revenue trends.
- Monitor available stock and inventory valuation.
- Identify low-stock products and potential stockout risks.
- Calculate reorder points and recommended reorder quantities.
- Estimate the number of days remaining before stock depletion.

## Reports Developed

### 1. Sales Analysis Report
- Revenue analysis
- Sales trends
- Top-selling products
- Product demand analysis

### 2. Inventory Analysis Report
- Available stock levels
- Total inventory value
- Excess inventory identification
- Inventory distribution

### 3. Stock Risk Analysis Report
- Low-stock product identification
- Stockout risk analysis
- Products requiring immediate attention

### 4. Reorder Recommendation Report
- Reorder point calculations
- Days of stock remaining
- Recommended reorder quantities
- Inventory replenishment insights

## Tools & Technologies

- Data Cleaning and Transformation

## Project Workflow

1. Collected product inventory and sales data.
2. Cleaned and transformed the dataset.
3. Created additional calculated columns and measures.
4. Established relationships between relevant tables.
5. Developed four interactive Power BI reports.
6. Analyzed inventory risks and generated reorder recommendations.

## Business Impact

The dashboard provides insights to help businesses:
- Reduce inventory shortages.
- Avoid unnecessary excess stock.
- Improve inventory planning.
- Make informed purchasing and replenishment decisions.
